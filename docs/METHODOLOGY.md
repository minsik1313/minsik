# ngspice 계산 속도·정확도 동시 개선 방법론

본 문서는 ngspice(및 Berkeley SPICE 계열) 시뮬레이터의 **계산 속도**와
**수치 정확도**를 동시에 끌어올리는 방법론을 정리하고, 그 방법론을 실제로
구현·검증한 프로토타입 엔진 **FastSpice**(`/fastspice`)를 제시한다.
모든 정확도 주장은 해석해(closed-form)와 비교한 측정값으로 뒷받침된다.

---

## 1. 문제 정의 — SPICE는 무엇을 계산하는가

과도해석(transient)에서 SPICE는 매 시간스텝마다 다음을 푼다.

```
  F(x(t)) = G·x + d/dt q(x) - b(t) = 0      (수정 노드 해석, MNA)
```

- `x` : 노드 전압 + (전압원·인덕터) 분기 전류
- `q(x)` : 전하/자속 (커패시터·인덕터의 상태량)
- 비선형 소자(다이오드·MOS)는 `F`를 비선형으로 만든다.

따라서 매 스텝은 **(a) 시간 미분의 이산화(적분기)** + **(b) 비선형
대수방정식의 Newton 반복** + **(c) 각 Newton 반복마다 희소 선형계 풀이**의
삼중 루프다. 속도와 정확도는 이 세 축에서 결정된다.

```
  for 각 시간스텝 t_n:                # ← (a) 적분기 / 스텝 크기 제어
      while not 수렴:                 # ← (b) Newton 반복
          J·Δx = -F  를 조립·풀이      # ← (c) 희소 LU
```

## 2. ngspice의 구조적 병목

| 축 | ngspice 기본값 | 한계 |
|----|----------------|------|
| 적분기 | 사다리꼴(TR) 또는 Gear | TR은 **수치 링잉**(거짓 진동), Gear는 **인공 감쇠**로 진폭·Q 왜곡 |
| 스텝 제어 | LTE 기반이나 보수적 | 매끄러운 구간에서도 스텝을 충분히 키우지 못해 스텝 과다 |
| 선형 솔버 | Sparse1.3 (Kundert, 1988) | 매 분해마다 재정렬(reordering) 반복 — 반복 풀이에 비효율 |
| 비선형 수렴 | 한정된 limiting | 바이어스 점프·콜드 스타트에서 수렴 실패(`gmin`/`source step` 보조 필요) |
| 병렬성 | 부분적 OpenMP | 소자 평가/행렬 풀이의 데이터 병렬성 미활용 |

핵심 통찰: **정확도와 속도는 상충하지 않는다.** 더 정확한 적분기는 같은
오차를 *더 큰 스텝*으로 달성하므로 스텝 수가 줄어 *더 빠르다.* 더 강건한
Newton은 발산·재시도를 줄여 *더 빠르다.* 즉 올바른 수치 선택은 두 마리
토끼를 동시에 잡는다.

## 3. 정확도 개선 방법론

### 3.1 적분기: TR-BDF2 (핵심)

사다리꼴(TR)은 2차 정확도이지만 A-안정일 뿐 **L-안정이 아니다.** stiff한
고유값 `λ`에 대해 증폭률이

```
  R(λh) = (1 + λh/2) / (1 - λh/2)  ──(λh→ -∞)──>  -1
```

로 −1에 수렴한다. 진폭이 줄지 않고 **부호가 매 스텝 뒤집히는 거짓 진동**
(트래피조이덜 링잉)이 그 결과다. 불연속(스위칭·계단 입력) 직후 특히 심하다.

**TR-BDF2**(Bank et al., 1985)는 한 스텝을 두 단계로 쪼갠다.

1. **단계 1 (TR)**: `[t_n, t_n + γh]` 구간을 사다리꼴로 전진 → 중간점 상태.
2. **단계 2 (BDF2)**: `(t_n, t_n+γh, t_n+h)` 세 점으로 BDF2 전진.

`γ = 2 − √2`를 택하면 두 단계의 Jacobian 계수가 같아져 재인수분해를 아끼고,
**L-안정**(`R(λh)→0`)이 되어 링잉이 사라진다. 그러면서 **2차 정확도**를
유지하고, 1차인 후진 오일러(BE)와 달리 정밀하다.

> 측정(본 저장소 벤치마크):
> - 수렴 차수 — BE 1.00, TR 2.00, **TR-BDF2 2.00** (이론값 일치)
> - 오차 상수 — 동일 스텝에서 **TR-BDF2가 TR보다 약 2배 정확**
> - stiff 계단 응답의 거짓 진동 — **TR 0.122 → TR-BDF2 0.020 (약 6배 감소)**

### 3.2 LTE 기반 적응 시간스텝

국소 절단 오차(LTE)를 추정해 허용오차 안에서 스텝을 키운다. 2차 방법의
국소 오차는 `~ h³·y'''`. 누적된 해의 **3차 분할차분(divided difference)**으로
`y'''`를 추정하고

```
  err = max_i |LTE_i| / (reltol·|x_i| + vntol)
  h_new = 0.85 · h · err^(-1/3)        (PI 형 제어, 성장 상한 적용)
```

로 스텝을 조절한다. 매끄러운 구간은 큰 스텝, 급변 구간은 작은 스텝 →
**같은 정확도를 더 적은 스텝으로**.

> 측정: RC 정현파, 고정 5e-6 스텝(4000스텝, maxerr 1e-6) 대비
> 적응 reltol=1e-4에서 **285스텝으로 14배 적게**, 오차 2.95e-4로 reltol에
> 비례 제어 확인.

### 3.3 강건한 Newton + 호모토피

비수렴은 정확도 문제이자(타임아웃 시 부정확한 결과) 속도 문제(재시도)다.
3중 방어선:

1. **소자 리미팅** — pn 접합 전압을 스텝 내에서 제한(`pnjlim`)해 지수함수
   오버플로/발산 방지.
2. **gmin 스테핑** — 모든 노드-접지 컨덕턴스를 크게 풀었다가 점진적으로
   조여 쉬운 문제→어려운 문제로 추종.
3. **소스 스테핑** — 독립 전원을 0→정격으로 램프.

2·3은 연속법(continuation/homotopy)으로, 콜드 스타트에서 Newton이 발산하는
회로도 수렴시킨다.

### 3.4 수렴 판정 — 상대/절대 혼합 허용오차

전압은 `reltol·|v| + vntol`, 전류는 `reltol·|i| + abstol`로 스케일별
허용오차를 둔다. 단일 절대 오차는 큰/작은 신호에서 동시에 적절하지 못하다.

## 4. 속도 개선 방법론

### 4.1 희소 선형 솔버: Sparse1.3 → KLU

회로 행렬은 행당 비영원소가 수 개뿐인 **극희소·비대칭** 행렬이며, 과도해석
내내 **희소 패턴이 불변**이다. 따라서:

- **심볼릭 분해 1회** (열 정렬 AMD/COLAMD, 기호적 채움 분석)
- **수치 재인수분해 다회** (값만 갱신)

로 쪼개면 반복 풀이 비용이 급감한다. SuiteSparse **KLU**(Xyce·상용 SPICE가
채택)가 회로 행렬에 최적화된 표준 선택이다. 본 프로토타입은 `linsolve.py`에서
이 "1회 정렬·다회 분해" 인터페이스를 노출하고(현재 백엔드 SuperLU, KLU 바인딩
가용 시 자동 승급), 비용 모델을 실제 도구와 일치시킨다.

### 4.2 적응 스텝 = 속도

§3.2의 적응 스텝은 정확도 기법이자 속도 기법이다. 스텝 수가 8~25배 줄면
(전체 삼중 루프가 그만큼 덜 도므로) 거의 비례해 빨라진다.

### 4.3 소자 평가 병렬화

각 소자의 stamp(부하 계산)는 **서로 독립**이다 → 데이터 병렬.
- **스레드 병렬(OpenMP)**: 소자들을 스레드로 분할, 행렬에 원자적 누적 또는
  스레드-로컬 버퍼 후 합산.
- **SIMD/벡터화**: 동일 모델(BSIM 등) 소자를 SoA로 묶어 벡터 평가.
- **GPU**: 대규모 소자 평가 + 희소 풀이 오프로딩(대형 회로에서 유효).

본 프로토타입은 stamp 인터페이스를 부작용 없는 누적 형태(`Stamper`)로
설계해 병렬화가 가능한 구조를 갖춘다(레퍼런스 구현은 단일 스레드).

### 4.4 멀티레이트 / latency 활용

회로의 부분마다 시간 척도가 다르다(빠른 디지털 vs 느린 바이어스). 느린
부분은 매 스텝 갱신을 생략(latency exploitation)하거나 부분별 다른 스텝을
쓰면 큰 회로에서 추가 가속이 가능하다(향후 작업).

## 5. 새 도구 아키텍처 — FastSpice

```
  parser.py      SPICE 넷리스트(부분집합) 파서
  circuit.py     MNA 인덱싱 + 희소 조립(Stamper)
  devices.py     R·C·L·V·I·다이오드 + 소스 파형, 동반모델 stamp
  integrators.py BE / TR / Gear2(가변스텝 BDF2) / TR-BDF2  ← 정확도 핵심
  newton.py      댐핑 Newton + gmin/소스 스테핑 호모토피   ← 강건성
  linsolve.py    희소 LU(심볼릭 재사용 인터페이스)         ← 속도 핵심
  analyses.py    DC 동작점 + 적응 과도해석 드라이버
```

설계 원칙: **모듈마다 한 가지 수치 결정**을 캡슐화해 개별적으로 교체·벤치마크
가능하게 한다(예: 적분기만 바꿔 TR↔TR-BDF2 비교).

## 7. 실제 ngspice에 적용하는 로드맵

본 방법론은 ngspice 코드베이스에도 점진 적용 가능하다.

1. **선형 솔버 교체** (가장 큰 즉효): `CKTload`/`spMatrix` 경로를 KLU로.
   ngspice는 이미 실험적 KLU 옵션이 있어, 기본화 + 심볼릭 재사용 강화.
2. **TR-BDF2 적분기 추가**: `NIiter`/`CKTterr`의 적분 계수 테이블에 TR-BDF2
   단계를 추가하고 `.options method=trbdf2` 노출.
3. **적응 스텝·LTE 정비**: `CKTtrunc`의 분할차분 LTE를 PI 제어로 보강.
4. **소자 평가 병렬화**: `CKTload` 루프를 OpenMP 분할 + 스레드-로컬 stamp 버퍼.
5. **호모토피 강화**: gmin/source 스테핑 스케줄 자동화.

각 단계는 독립적으로 검증·도입할 수 있어 위험이 낮다.

## 8. 한계와 향후 작업

- 본 프로토타입은 R·C·L·V·I·다이오드까지 지원(BSIM MOS·전송선은 향후).
- 선형 솔버 백엔드는 현재 SuperLU(데모용); 생산용은 KLU 바인딩 연결.
- 병렬 소자 평가는 인터페이스만 마련(실측 가속은 멀티코어 빌드에서).
- 주파수(AC)·잡음·몬테카를로 해석 미구현.

이 한계들은 본 방법론의 일반성을 해치지 않으며, §5 모듈 구조 위에서 추가
가능하도록 설계되었다.
