### Machine A 대안
- **단일카드**: RTX 6000 Blackwell 96GB ×1 (~13,000,000+) — 구성 단순, 더 큰 모델
- **가성비**: RTX 4090 24GB(중고) ×2 = 48GB (~5,500,000) — 32B급까지 쾌적

### Machine B 업그레이드 (대형 SoC 리그레션 상시화 시)
- CPU/플랫폼: Threadripper 7960X(24C)/7970X(32C) + TRX50 + 256GB ECC RDIMM (+5,000,000~7,000,000)
- 트레이드오프: 코어·ECC·메모리 대역폭↑ vs 피크 클럭↓(싱글스레드 SPICE는 9950X3D가 유리)

## 총계

| 구성 | 권장 합계(KRW) |
|---|---:|
| Machine A | ~10,500,000 |
| Machine B | ~4,350,000 (RAM/저장 증설 시 ~7,000,000) |
| 네트워크/스케줄 | ~250,000 |
| **총계** | **~15,000,000 – 18,000,000** |

- 예산(1~3천만) 내 충분. 남는 예산은 **A를 RTX 6000 96GB 단일카드**로 올리거나
  **B를 Threadripper+256GB ECC**로 확장하는 데 배분 가능.
- 상용 EDA(Cadence/Synopsys/Vivado) 라이선스는 **별도**이며 위 하드웨어로 구동에 충분.
