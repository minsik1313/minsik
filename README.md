# 1인 Fabless 설립 프로젝트

오픈소스 EDA 기반 **1인(혼자) 운영 fabless 반도체 회사** 설립을 위한 계획 저장소.

- **전략:** 오픈소스 EDA 부트스트랩(라이선스 비용 0)
- **도메인:** 혼성신호(Mixed-Signal) SoC — 디지털 코어 + 아날로그 IP
- **수익 모델:** 자체 칩 제품 판매
